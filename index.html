Iron Shield Security Audits

Audit results and verified resolutions for vulnerabilities identified up to Sprint 231.

AUDIT-190-FS RESOLVED

Symlink-Bypass in FS

Syntactic directory checks failed when handling symbolic links, allowing file modifications outside the workspace sandbox.

Patch Diff (executor.rs):

+ for component in check_path.components() { + accumulated.push(component); + if accumulated.exists() { + if std::fs::symlink_metadata(&accumulated)?.file_type().is_symlink() { + return Err("Symlink blocked"); + } + } + }
AUDIT-193-NET RESOLVED

DNS Suffix Bypass

Domains matching suffix checks (ends_with) allowed hijacking (e.g. evilgoogle.com matching google.com whitelists).

Patch Diff (bridge.rs):

- domain.ends_with(d) || domain == d.as_str() + domain == d.as_str() || domain.ends_with(&format!(".{}", d))
AUDIT-190-NET RESOLVED

Synchronous Network Hangs

HTTP requests lacked timeouts. A non-responsive web server could lock the execution thread and bypass the watchdog limit.

Patch Diff (bridge.rs):

- ureq::get(url).call() + ureq::get(url) + .timeout(std::time::Duration::from_secs(5)) + .call()
AUDIT-190-GPU RESOLVED

GPU Buffer Jitter

Object maps flat-serialized in hash order resulting in random float alignments and unstable WGPU compute dispatches.

Patch Diff (window.rs):

+ let mut keys: Vec<&String> = map.keys().collect(); + keys.sort(); + for k in keys { + collect_floats(map.get(k).unwrap(), out); + }
AUDIT-190-JIT RESOLVED

JIT FFI Panic Crashes

Uncaught native module panics terminated the host process in JIT mode, bypassing general exception routing.

Patch Diff (executor.rs):

+ let result = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| { + mod_.handle(name, &v_args, &self.permissions) + })); + match result { + Ok(Some(res)) => return res, + Err(_) => return ExecResult::Fault { ... } + }
AUDIT-230-JIT RESOLVED

JIT Loop Watchdog

Implemented iterative execution loop watchdog in JIT mode, terminating infinite while loops after 50ms.

Patch Diff (evaluator.rs):

+ let jit_start = std::time::Instant::now(); + let mut jit_iters = 0; + while let Value(Bool(true)) = self.evaluate_inner(cond) { + self.evaluate_inner(body)?; + jit_iters += 1; + if jit_iters.is_multiple_of(1000) && jit_start.elapsed().as_millis() >= 50 { + return Err("Watchdog: JIT timeout (50ms)"); + } + }
AUDIT-231-VM RESOLVED

VM Watchdog Bypass

Tight loops invoking fast FFI commands previously reset the watchdog timer indefinitely, bypassing timeout bounds.

Patch Diff (machine.rs):

+ let mut accumulated_cpu = std::time::Duration::ZERO; + // Every 1000 instructions: + if accumulated_cpu + start.elapsed() >= 50ms { return Err("Watchdog"); } + // Before FFI: + accumulated_cpu += start.elapsed(); + // After FFI: + start = Instant::now();
AUDIT-223-AUDIO RESOLVED

Audio Mutex Contention

CPAL AudioManager was locked via static Mutex inside the render loop, causing major lock contention and frame drops.

Patch Diff (audio.rs):

+ // Spawns dedicated AudioThread channel worker + let (tx, rx) = mpsc::channel::(); + thread::Builder::new().name("AudioThread").spawn(move || { + while let Ok(cmd) = rx.recv() { match cmd { ... } } + }); + // FFI calls are non-blocking fire-and-forget + self.tx.send(AudioCommand::PlayTone { ... });
